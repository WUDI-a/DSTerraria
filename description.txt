---

DSTerraria: a tModLoader mod that lets an AI take over Terraria and play autonomously.

Perception, pathfinding, building and combat are exposed as callable tools, and a large
language model (DeepSeek) decides what to do — explore, mine, craft, build houses and fight
bosses from scratch, fully hands-free.

Chat commands:
  /start        start AI autonomous play
  /start stop   stop
  /halt         emergency stop
  /vis          toggle the debug overlay
  /<natural language>  issue an instruction directly, e.g. /home /mine

Fill in Agent API Key / Base URL / model (DeepSeek) in the mod config.

(Optional) DragonLens: disable spawns / godmode / fast-forward.

Source and details: https://github.com/WUDI-a/DSTerraria
